Over the past few years, the Internet has evolved from preserve of static HTML pages to the cutting edge of dynamic, user interactive presentation. This has been possible with introduction of scripting languages like PHP. PHP-Nuke is a working example of this technology. The Nuke portal system has beautifully integrated the core functionality of the PHP language. The entire software is so flexible as well as so easy, that maintaining a large database driven interactive website becomes a child play.
